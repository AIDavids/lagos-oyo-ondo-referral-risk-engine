# Raw CSV inputs (bronze uploads)

Copy these three files here so anyone can rebuild the pipeline from this repo:
- facilities_v2_0.csv        (made by scripts/clean.py from GRID3 NGA Health Facilities v2.0)
- lga_boundaries.csv         (made by scripts/clean.py from the GRID3 LGA boundary shapefile)
- lga_pop_total_scaled.csv   (WorldPop/GRID3 NGA Population v3.0, LGA table)

All three are open data under CC BY 4.0. Keep the attribution in the main README.
